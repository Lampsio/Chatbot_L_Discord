# Chatbot L

## Overview
Chatbot L is an advanced conversational AI inspired by the character L from the popular anime "Death Note." This chatbot possesses short-term and long-term memory capabilities, can remember names, and has knowledge and thinking patterns characteristic of L. Additionally, it generates nicknames for interlocutors and stores all conversation data in MongoDB. The chatbot is integrated with a Discord bot, allowing users to interact with it on Discord channels. All features were built from scratch.

## Features
- **Memory Management**: Short-term and long-term memory capabilities.
- **Name Recognition**: Ability to remember and recognize names.
- **Character Knowledge**: Knowledge and thinking patterns inspired by L from "Death Note."
- **Nickname Generation**: Creates nicknames for interlocutors.
- **Data Storage**: All conversation data is stored in MongoDB.
- **Discord Integration**: Interact with the chatbot on Discord channels via a Discord bot.

## Technologies
- **MongoDB**: Used for storing conversations and related data.
- **Discord.py**: A library for creating Discord bots.
- **Langchain**: Used for managing control over large language models (LLMs).

## Setup

### Prerequisites
- Python 3.8 or higher
- MongoDB instance
- Discord bot token
